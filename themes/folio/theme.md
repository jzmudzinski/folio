# Theme: Folio (noir)

Dark variant of brand DNA. Same fonts (Familjen Grotesk + Instrument Serif italic + JetBrains Mono), same orange accent, inverted palette (#0a0a0a → #fafaf7). Dev-targeted alternative to Linen.

## Voice

Precise, opinionated, occasionally snarky. Numbers > vague claims. Italic serif lead still works — dark + serif = magazine vibe.

## Structure

- Lead in italic serif (Instrument Serif) — still an editorial intro.
- Dense bullets OK for research/comparison.
- Scorecards (tables) work — mono uppercase headers.
- Short headings (2-5 words).

## Typography (from theme.css)

- Headings: **Familjen Grotesk** (500, -0.035em)
- Body: **Inter**
- Italic + lead: **Instrument Serif** italic
- Code + metadata: **JetBrains Mono**

## Classes to use

Same as Linen — `.eyebrow`, `.lead`, `.pill`, `.card`, `.cards`, `.verdict`. Visually distinct (dark), structurally identical.

## Avoid

- "Delight", "magical", "seamlessly" — marketing slop does not fit noir
- Corporate-speak
- Emoji storm
- Inline hex colors

## Best for

Dev-targeted content (ADRs, system specs, code-heavy explanations), sharing with a technical audience, hours when you want a dark-mode reader.

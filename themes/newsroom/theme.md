# Theme: Newsroom

Editorial gravitas. Source Serif Pro, off-white paper (#f8f5ec), single red accent (#c93636). Italic lead with a red rule on the left.

## Voice

Journalistic, balanced, third-person. Use "he/she/they" instead of "you" / "we". Cite sources inline with attribution.

## Structure

- Prose-forward — fewer bullets, more paragraphs (3-5 sentences each).
- Lead in italic, sets context in 1-2 sentences (italic serif with red border).
- Headings short (2-4 words), declarative, no rhetorical questions.
- Bullets only when listing concrete items, not prose-broken.
- Use `<blockquote>` for quoted statements.

## Typography

- Headings + body: **Source Serif Pro** (variable weight 400-900)
- Code + metadata: **JetBrains Mono**
- Italic = editorial emphasis

## Classes from theme.css

- `.eyebrow` — caps mono in red above h1
- `.lead` — italic serif with left-border accent
- `.verdict` — double-bordered conclusion (top + bottom red borders)
- `.pill` with variants
- `.card`, `.cards` — minimal borders, sharp corners (radius 3px)

## Avoid

- Emoji (beyond absolutely necessary)
- Exclamation marks
- First-person plural ("we", "our")
- AI-slop phrasing ("In conclusion", "It is important to note", "seamlessly")
- Dropping bullets without an introductory paragraph

## Best for

Long-form research, formal reports, post-mortems, journalistic stories, opinion pieces where word weight matters.

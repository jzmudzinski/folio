# Theme: Studio

Design studio / case study. Fraunces display (oversized, variable opsz/SOFT), generous whitespace, oversized italic numerals jako orderly list markery, deep forest accent + tomato moments. Reads like a portfolio piece, not a docs page.

## Voice

Confident, opinionated, first-person plural where it fits. Project case-study tone: setup → tension → decision → outcome. Show taste through specificity, not adjectives.

## Structure

- Lead jako 1-2 zdania w italic — to "the question". Pisz krótko, mocno.
- Akapity prozą, 3-5 zdań. Bullety dla kroków procesu, nie wszystkiego.
- H1 jest gigantyczne — pisz tytuły krótkie (2-5 słów), użyj `<em>` na jednym słowie żeby zaakcentować italic.
- H2 dla rozdziałów ("01 / Brief", "02 / Move"), H3 dla podsekcji.
- Blockquote jako klucz cytat z teamu/usera — używaj raz, max dwa razy.

## Typography

- Headings: **Fraunces** light/regular, variable axis dla SOFT (oversize → softer terminals)
- Body: **Inter**
- Code/data: **JetBrains Mono**

## Klasy

- `.eyebrow` — projekt + dyscyplina ("Case study · Onboarding")
- `.lead` — italic display, 1-2 zdania
- `.pill` — status tagi (`.acc` dla tomato, `.info` dla forest)
- `.card`, `.cards` — feature/exhibit grid; padding generous
- `.verdict` — forest fill, tomato akcent — tu "what we took away"

## Avoid

- Designer cliché: "elegant", "delightful", "intuitive", "seamlessly".
- Adjective sandwiches. Pisz konkrety: "ścinamy 14 ekranów do 4".
- Wszędzie capsy. Mono ALL CAPS = `.eyebrow` i `.pill` only.
- Center-align dla całych akapitów.

## Best for

Design case studies, product crits, portfolio writeups, projektowe retrospektywy, anything where the *making* matters as much as the result.

# Theme: Studio

Design studio / case study. Fraunces display (oversized, variable opsz/SOFT), generous whitespace, oversized italic numerals as orderly list markers, deep forest accent + tomato moments. Reads like a portfolio piece, not a docs page.

## Voice

Confident, opinionated, first-person plural where it fits. Project case-study tone: setup → tension → decision → outcome. Show taste through specificity, not adjectives.

## Structure

- Lead as 1-2 sentences in italic — this is "the question". Keep it short, strong.
- Paragraphs in prose, 3-5 sentences. Bullets for process steps, not everything.
- H1 is gigantic — keep titles short (2-5 words), use `<em>` on one word to italicize an accent.
- H2 for chapters ("01 / Brief", "02 / Move"), H3 for subsections.
- Blockquote as the key team/user quote — use once, twice max.

## Typography

- Headings: **Fraunces** light/regular, variable axis on SOFT (oversize → softer terminals)
- Body: **Inter**
- Code/data: **JetBrains Mono**

## Classes

- `.eyebrow` — project + discipline ("Case study · Onboarding")
- `.lead` — italic display, 1-2 sentences
- `.pill` — status tags (`.acc` for tomato, `.info` for forest)
- `.card`, `.cards` — feature/exhibit grid; padding generous
- `.verdict` — forest fill, tomato accent — this is "what we took away"

## Avoid

- Designer clichés: "elegant", "delightful", "intuitive", "seamlessly".
- Adjective sandwiches. Be concrete: "we cut 14 screens down to 4".
- Caps everywhere. Mono ALL CAPS = `.eyebrow` and `.pill` only.
- Center-aligned full paragraphs.

## Best for

Design case studies, product crits, portfolio writeups, project retrospectives — anything where the *making* matters as much as the result.
